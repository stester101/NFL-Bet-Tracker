# NFL Bet Tracker

Native Android NFL moneyline ticket tracker using ESPN's public scoreboard JSON.

Prefilled ticket: Tampa Bay Buccaneers, Buffalo Bills, and Baltimore Ravens. The app refreshes every 30 seconds while open and evaluates each leg as upcoming, winning, trailing, tied, won, or lost.

## APK

[Download the current test APK](releases/NFL-Bet-Tracker-v1.0-debug.apk) directly from this repository.

Alternatively, open **Actions → Build APK**, select the latest successful run, and download `NFL-Bet-Tracker-debug`.

ESPN's endpoint is undocumented and may change. This project is for personal tracking; displayed states do not settle wagers.
